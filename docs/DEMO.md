# 演示流程（可重复，约 3 分钟）

更新：2026-11-15（视觉改版 V4 交付）。所有步骤使用真实数据与确定性模拟；结果可在任意机器复现。

前提：`npm install && npm run dev`，浏览器打开 `http://localhost:5173`（英文界面；`#CNZH` 后缀为中文）。桌面 1440×900 体验最佳。

## 一条完整演示线

1. **选择目标（两段镜头）**
   点击左侧任务卡中的 **SITE-A · Delta front strata overlook**。
   镜头先聚焦站点，随后自动拉远到能框住**整条往返路线**的取景；右侧结果卡显示可行计划（约 2166 m / 91 min）。SITE-A/B/C 均可，结果数字来自路线内核。

2. **调整停留时间（生成新推演）**
   在"预算参数"中拖动 **科学停留时长** 滑杆（例如 30 → 60 分钟）。
   界面明确提示：更改参数会生成新的推演计划（播放重置）；结果卡的总时长/资源余量随之更新。

3. **启动任务并查看返航范围变化**
   点击 **开始远征**（速度 ×8）。3D 中琥珀色位置光柱沿贴地路线行进；底栏时间轴前进。
   随着资源消耗，**返航范围边界**（琥珀色覆盖层+边界线）开始从区域边缘向内收缩——它显示"以当前剩余资源，还能从哪些位置走回基地"。事件（电池损失 −45）会让边界瞬间大幅收缩。图例与"来源与假设"抽屉解释判据（模拟值、±1–2 格、"此刻能否回家"≠"任务能否完成"）。

4. **触发事件并回看**
   播放中点击 **电池损失 −45**（或选择左下"场景"里的预设：名义往返 / 采样中通道封闭 / 电池预留击穿 / 电池滞留）。
   封闭场景中：原路线变灰虚线、红色矩形标记封闭区、应急返航路线（琥珀）从精确事件位置重新规划。
   **拖动底部时间轴**回看任意时刻：宇航员位置、资源、事件日志、路线状态全部确定性回放；越过事故再回退，状态正确恢复；点击时间轴上的事件刻度直接跳到关键时刻。键盘 ←/→ 单步 ±1 分钟。

5. **对比两个方案**
   在结果卡点击 **锁定为方案 A**（当前计划被冻结）。
   调整任意条件（换站点 / 切换策略 / 改停留时长 / 改初始资源）→ 当前计划即"方案 B"，地图上出现方案 A 的灰白虚线路线与方案 B 并排；结果卡显示 A/B 逐项对比（距离/时长/氧气/电池/余量/可行性，Δ = B − A）。对比完成后点击 **解锁方案 A** 清除。

## 演示要点（评审常问）

- **数据真实性**：地形/影像为 NASA MRO CTX 真实产品；基地、事件、速度/消耗率、停留时长均为明确标注的模拟假设（"来源与假设"抽屉可查全部 6 条来源与假设注册表）。
- **确定性**：同一输入重放结果完全一致（引擎状态是模拟分钟 T 的纯函数）。
- **性能**：规划交互实测 ≤25 ms、返航范围场 ≤50 ms（Apple M4，真实浏览器；界面角落实时显示帧率与绘制调用数）。
- **局限**：估算基于 20 m 规划格与简化运动模型，不是导航或生命安全指导；返航范围边界按 ±1–2 格呈现对齐不确定度。
